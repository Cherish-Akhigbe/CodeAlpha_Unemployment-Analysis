# Unemployment Analysis with Python

## Project Overview
This project analyses unemployment in India from May 2019 to June 2020 using Python. It explores unemployment trends across time, regions, and rural and urban areas, investigates the impact of the Covid-19 lockdown, and presents insights that could inform economic and social policy.

**Dataset:** [Unemployment in India (Kaggle)](https://www.kaggle.com/datasets/gokulrajkmv/unemployment-in-india)

## Objectives
- Clean and prepare the unemployment dataset
- Explore unemployment trends over time, across regions, and between rural and urban areas
- Investigate the impact of Covid-19 on unemployment rates
- Identify key patterns and check for seasonal trends
- Present insights that could inform economic or social policies

## Tools and Technologies
- Python
- pandas and NumPy (data cleaning and analysis)
- Matplotlib and Seaborn (visualization)
- Jupyter Notebook / Google Colab

## Project Workflow
1. **Data loading:** imported the dataset from Kaggle
2. **Data cleaning:** fixed column names, converted dates, removed blank and duplicate rows
3. **Exploratory analysis:** examined trends over time, regional differences, and rural vs urban rates
4. **Covid-19 impact analysis:** compared pre-lockdown, lockdown, and post-lockdown periods
5. **Seasonal trend check:** looked for recurring monthly patterns
6. **Insights and recommendations:** summarised findings and suggested policy actions

## Key Learning Outcomes
- Cleaning and preparing real-world data with pandas
- Working with dates and time-based trends
- Creating clear visualizations, including line charts and heatmaps
- Comparing groups and time periods to measure the impact of an event
- Recognising data limitations, such as a short time span and missing values
- Turning data findings into practical policy recommendations
